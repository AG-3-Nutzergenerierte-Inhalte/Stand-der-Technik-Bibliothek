# Component Definitions

Dieser Bereich dient der gemeinsamen Erarbeitung und Diskussion von OSCAL Component Definitions innerhalb der AG3 der BSI Community.

## Ziele

- Austausch über den Aufbau von Component Definitions
- Veröffentlichung von Diskussionsgrundlagen
- Sammlung von Beispielen
- Entwicklung gemeinsamer Best Practices

## Inhalte

### BSI Contributions

Vom BSI bereitgestellte Dokumente, die als Diskussionsgrundlage veröffentlicht wurden.

### Community Contributions

Von Mitgliedern der Community erstellte Vorschläge, Beispiele und Weiterentwicklungen.
