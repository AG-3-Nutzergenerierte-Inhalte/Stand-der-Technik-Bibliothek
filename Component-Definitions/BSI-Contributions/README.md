# BSI Contributions

Dieser Ordner enthält Dokumente, die vom Bundesamt für Sicherheit in der Informationstechnik (BSI) der AG3 zur Veröffentlichung innerhalb der BSI Community zur Verfügung gestellt wurden.

## Zweck

Die Dokumente dienen als Diskussionsgrundlage für die gemeinsame Weiterentwicklung von OSCAL Component Definitions.

Es handelt sich um interne Arbeitsdokumente des BSI. Sie stellen keine verbindlichen Vorgaben für Hersteller oder andere Organisationen dar.

## Herkunft

Das BSI hat diese Dokumente der AG3 zur Veröffentlichung innerhalb der BSI Community bereitgestellt, um Transparenz über den aktuellen Arbeitsstand zu schaffen und den fachlichen Austausch innerhalb der Community zu fördern.
